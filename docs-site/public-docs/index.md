# AI Team

AI Team 是以 Slack 為介面的 AI 軟體團隊協調器，透過配置式流程，
讓不同角色的 AI agents 協作處理軟體開發任務。

系統以 Java 21 與 Spring Boot 建置，整合 Claude Code、Codex 等 CLI runtime。
流程包含需求整理、設計、測試計畫、實作、驗收與程式審查，最後由真人核准發布。

## 設計重點

- **配置式角色與流程**：依專案需求安排角色與工作節點。
- **需求追溯**：連結需求、驗收條件與驗證結果。
- **人工核准**：保留重要決策與發布的真人控制點。
- **工作連續性**：保存進度與結構化交接摘要，協助長任務接續。
- **明確的驗證證據**：區分程式測試、部署檢查與真實端對端驗證。

本網站只提供公開介紹。內部操作手冊、環境設定、部署紀錄、連線資訊與交接紀錄不在公開範圍內。
