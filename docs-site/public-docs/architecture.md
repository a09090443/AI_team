# 架構概要

系統以協調器管理 AI 團隊的工作進度，將模型執行與流程控制分離。

| 層次 | 職責 |
|---|---|
| Slack 介面 | 接收需求、呈現進度與人工決策 |
| 流程協調 | 管理節點、任務狀態、佇列與角色交接 |
| 團隊配置 | 定義角色、提示與流程契約 |
| Runtime adapter | 呼叫不同 AI CLI 並處理執行結果 |
| 執行沙箱 | 限制執行範圍與工具能力 |
| 狀態與稽核 | 保存任務進度、檢查點與驗證證據 |

協調器負責狀態與契約，agents 負責各自的專業工作。
角色回報仍須通過流程檢查；模型自行宣稱完成，不等於系統驗收成功。

部署設定、環境識別、憑證與主機連線資訊留在私人環境管理，不由本網站提供。
